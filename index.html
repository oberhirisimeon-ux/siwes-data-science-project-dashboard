GETTING STARTED

How to use this dashboard

1. Upload data

Choose a CSV, XLSX, or XLS file. For Excel, choose the worksheet you want to analyse.

2. Check quality

Review validation alerts and missing values before trusting the results.

3. Clean safely

Remove duplicates, fill missing values, or rename fields. Undo and Reset protect your original upload.

4. Build charts

Choose columns, calculations, chart type, or a date trend. Download any current chart as a PNG.

5. Understand relationships

Correlation close to +1 or -1 means a stronger relationship. It does not prove one value causes another.

6. Save and share

Use snapshots for versions. Sign in for cloud saving, or create a settings-only share link.

7. Export results

Download filtered data as CSV or create a PDF report for submission and presentations.

Privacy note

Without an account, data stays in this browser. Cloud saving sends your dashboard data to your private Supabase workspace.
